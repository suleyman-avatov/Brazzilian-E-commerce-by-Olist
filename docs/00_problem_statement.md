# Постановка задачи

## Контекст
Olist: бразильский маркетплейс, данные за 2016-2018 гг.

## Главный вопрос
Как задержки доставки влияют на оценки клиентов и повторные покупки, и сколько выручки на этом теряется?

## Подвопросы
1. Какая доля заказов приходит позже обещанной даты и как это меняется по времени, регионам и категориям?
2. Как задержка влияет на оценку в отзыве (`review_score`)?
3. Возвращаются ли клиенты после плохого опыта реже, чем после хорошего?
4. Сколько выручки связано с проблемными заказами и какой эффект даст улучшение?

## Метрики

Общие правила для всех метрик:
- в расчёт берутся только заказы со статусом `delivered` и непустой `order_delivered_customer_date`;
- клиент определяется по `customer_unique_id` (не по `customer_id`, который уникален для каждого заказа);
- все метрики считаются в аналитическом периоде (см. ниже).

| Метрика | Определение | Колонки / таблицы |
|---|---|---|
| **Задержка заказа (флаг)** | Заказ доставлен позже обещанной даты: `is_late = 1`, если `order_delivered_customer_date` > `order_estimated_delivery_date` | `orders` |
| **Величина задержки (дни)** | `order_delivered_customer_date` − `order_estimated_delivery_date`; положительное значение = опоздание | `orders` |
| **Доля заказов с задержкой** | Число заказов с `is_late = 1` / число всех доставленных заказов | `orders` |
| **Срок доставки (дни)** | Среднее значение `order_delivered_customer_date` − `order_purchase_timestamp` по доставленным заказам | `orders` |
| **Оценка заказа** | `review_score` из `order_reviews`. Если у заказа несколько отзывов, берётся последний по `review_answer_timestamp` (решение фиксируется на этапе staging) | `order_reviews` |
| **Средняя оценка** | Среднее значение оценки заказа | `order_reviews` |
| **Плохая / хорошая оценка** | Плохая: 1-2, нейтральная: 3, хорошая: 4-5 | `order_reviews` |
| **Стоимость заказа** | Сумма `price` + `freight_value` по всем позициям заказа | `order_items` |
| **Выручка проблемных заказов** | Сумма стоимости заказов с `is_late = 1` | `orders`, `order_items` |
| **Доля повторных покупателей** | Клиенты с 2+ доставленными заказами / все клиенты | `orders`, `customers` |
| **Повторная покупка в окне 180 дней** | Клиент сделал второй заказ в течение 180 дней после даты покупки первого заказа (`order_purchase_timestamp`) | `orders`, `customers` |
| **Средний чек повторного заказа** | Средняя стоимость заказов, следующих за первым | `orders`, `order_items` |
| **Потенциальная потеря выручки** | Число клиентов с задержкой в первом заказе × (доля повторных покупок у клиентов без задержки − доля у клиентов с задержкой) × средний чек повторного заказа | производная метрика |

## Источник данных и ограничения
- **Источник:** Kaggle, Brazilian E-Commerce Public Dataset by Olist.
- **Диапазон данных в источнике:** 04.09.2016 - 17.10.2018 (по `MIN`/`MAX` от `order_purchase_timestamp` в таблице `orders`).
- **Аналитический период:** 01.01.2017 - 31.08.2018. Причина: в конце 2016 года заказов очень мало, а после августа 2018 года данные обрываются и неполны, поэтому берётся период с устойчивым потоком заказов.
- **Окно наблюдения для повторных покупок:** 180 дней. В когорту попадают клиенты, у которых первый заказ сделан не позже чем за 180 дней до конца периода (то есть примерно до 04.03.2018), иначе у них не было возможности вернуться. Точную дату проверить по данным.
- **Ограничения:**
  - данные обезличены, причины задержек неизвестны;
  - повторных покупателей мало, поэтому оценки делаются с доверительными интервалами, а выводы формулируются осторожно;
  - связь «задержка → возврат» может объясняться другими факторами (категория, регион, продавец), поэтому мы показываем связь, а не доказываем причину;
  - отзывы есть не у всех заказов, у части заказов несколько отзывов;
  - данные за 2016 год и конец 2018 года неполные.

## Гипотезы для проверки
- **H1:** чем больше задержка, тем ниже оценка заказа.
- **H2:** клиенты, оставившие плохую оценку (1-2), реже совершают повторную покупку в течение 180 дней, чем клиенты с хорошей оценкой (4-5).
- **H3:** доля клиентов, совершивших повторную покупку в течение 180 дней после первого заказа, ниже среди тех, чей первый заказ был доставлен с задержкой, чем среди тех, у кого он пришёл вовремя. Проверка: разница долей с доверительным интервалом и тест для двух пропорций.
- **H4 (по желанию):** доля задержек выше в удалённых регионах и в тяжёлых категориях товаров.

Оценка потери выручки (LTV) не является отдельной гипотезой: она рассчитывается по результату H3 и относится к подвопросу 4.
